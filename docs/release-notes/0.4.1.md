Run Command in Terminal is gone, and the command line's terminal button simply opens
your terminal.

## Changes

- **Run Command in Terminal is removed.** It was meant to run what you typed in the
  command line in your terminal app, on ⌘Return, but the key never reached it. Commands
  from the command line run in Drevo's console, as before. If your `keybindings.json`
  has an entry for `shell.runInTerminal`, Drevo now skips it as an unknown command.
- **The terminal button opens your terminal.** The button at the right of the command
  line opens your terminal app in the selected folder, or else in the current one, like
  ⌥⌘T. Before, it ran the typed command there.

## Install

From 0.4.0, choose Drevo ▸ **Check for Updates…**. Otherwise download
`Drevo-0.4.1.dmg`, open it and drag Drevo to Applications. It needs macOS 14 Sonoma or
later on an Apple Silicon Mac. The app is signed with a self-signed certificate, so the
first time you open it macOS says it couldn't verify it: click Done, then go to System
Settings ▸ Privacy & Security and click **Open Anyway**.
