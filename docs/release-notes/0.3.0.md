Every shortcut in Drevo can now be changed in Settings, without editing a file.

## New: edit shortcuts in Settings ▸ Keys

- **Change a key by pressing it.** Settings ▸ Keys lists every command with its keys.
  Click a key and press the new one. Click **+** to add another key, or hover over a key
  and click **×** to remove it. **↺** resets one command, and **Reset All…** resets
  every one.
- **Find commands fast.** Search by name or by key ("rename", "f5", "⌘D"). **Changed**
  shows only the shortcuts you changed.
- **No silent clashes.** If a key already belongs to another command, Drevo asks before
  moving it ("⌘D is Duplicate's shortcut. Use it here instead?"). It refuses macOS
  system shortcuts, your global "Show Drevo" shortcut and fixed menu keys such as ⇧⌘W.
  It also says when a plain key (a letter, Tab, an arrow) only works in the file list.
- **Changes apply at once** to menus, the key-hint bar, the command palette and Help ▸
  Keyboard Shortcuts.
- **`keybindings.json` still works.** The editor saves there, writes only what differs
  from the defaults, and keeps the rest of your entries. It follows a symlinked file
  (from a dotfiles folder, say) and leaves the link in place. If the file can't be read,
  the editor says so and won't overwrite it.

## Improvements

- **Every key you add works like the first.** A menu shows one shortcut per command.
  Any other ⌘, ⌃ or F-key you give a command now works wherever the menu key does.
  Before, those keys worked only while the file list had focus. Extra keys for Copy,
  Paste, Undo and Select All work in text fields too.
- **The Return-key setting keeps Return working.** Switching General ▸ Return key
  between "opens" and "renames" moves Return between Open and Rename, even after you've
  changed their other keys.
- **Esc with modifiers can be a shortcut.** ⌥Esc and similar combinations now reach
  their command while a filter or search is active. A plain Esc still clears the filter.
- **Backspace always fixes the filter first.** While you're typing a filter, Backspace
  shortens it, even if you bound Backspace to a command such as Move to Trash.

## Fixes

- Starting a shell command just as the previous one finished could interfere with the
  new one. A command now counts as running until the console has shown how it ended.

## Install

Download `Drevo-0.3.0.dmg`, open it and drag Drevo to Applications. It needs macOS 14
Sonoma or later on an Apple Silicon Mac. The app is signed with a self-signed
certificate, so the first time you open it macOS says it couldn't verify it: click
Done, then go to System Settings ▸ Privacy & Security and click **Open Anyway**.
